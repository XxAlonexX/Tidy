// privacy, plainly

Exactly what leaves your Mac.

No accounts, no analytics and no Tidy servers. Here is the complete list.

Stays on your Mac

  • Every file sorted by a rule: nothing is sent
  • The contents of photos, videos, PDFs and documents
  • Folder paths and your Desktop layout
  • The undo log (.jev-cleaner-manifest.json)

Sent to TypeSafe (only for Jev)

  • File name, extension, size and modified date
  • For plain-text files only: the first 600 characters
  • Sent directly from your Mac, using your own API key

Sent to Dodo Payments (only if you buy)

  • Your license key and your Mac's name, to activate it
  • A license check about once a week
  • A failed network check never locks you out

// questions

Good questions.

Can it delete or lose my files?

No. Tidy only moves files into new folders, inside the same folder, and only after you press Move files. If a name is already taken, it adds a number instead of overwriting. Every move is logged, so Undo can put each file back where it was.

Do I need a TypeSafe API key?

Not to get started. Screenshots, recordings, documents, code, archives and audio are sorted by rules without any key. A key switches on Jev for files whose names don't give them away. Paste it in Settings and it's saved in your Keychain.

What is Jev?

Jev is TypeSafe's small, fast judgment model. Tidy gives it the file name, type, size, date and (for text files) a short preview. Jev picks one of the nine folders and says how confident it is. Your confidence bar decides whether the file moves or waits for you.

Can I clean folders other than the Desktop?

Yes. Press ⌘O or click the folder name in the top-left corner to choose Downloads, Documents or any other folder.

Which Macs does it run on?

Any Mac with macOS 13 Ventura or later, Apple silicon or Intel. It's a single universal app under 1 MB.

macOS says the app can't be checked for malware. What do I do?

If you see this, right-click Tidy in Applications and choose Open, then confirm. You only need to do this once.
